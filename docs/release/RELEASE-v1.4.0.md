# Release v1.4.0 - Notion 风格改造

**发布日期**: 2026-03-03
**Sprint ID**: sprint-2026-03-02-notion-redesign

---

## 版本说明

将 Pie 日历应用全面改造成 Notion 风格，提供简洁、模块化、高效的日程管理体验。

## 主要变更

### ✨ 新功能

#### 1. Notion 风格视觉设计
- 简洁黑白灰配色方案
- 圆角卡片设计 (4px/8px/12px)
- 悬浮阴影效果
- 支持明暗主题切换

#### 2. 侧边栏导航系统
- 可折叠左侧导航栏
- 树状结构组织日历
- 拖拽排序功能
- 桌面端 (240px 展开 / 60px 收起)
- 移动端抽屉式菜单

#### 3. 命令菜单 (Cmd+K / Ctrl+K)
- 快速访问所有功能
- 15+ 内置命令
- 响应时间 < 100ms
- 支持键盘导航

#### 4. 模块化内容区
- 日程以块(block)形式呈现
- 支持拖拽重组
- 四种视图模式：
  - 列表视图
  - 看板视图
  - 时间轴视图
  - 日历视图

#### 5. 快速创建
- 自然语言解析
- 支持中英文输入
- 自动提取时间、地点、优先级

### 🔧 技术改进

- 更新至 Electron 25
- 优化首屏加载时间 (< 2s)
- 虚拟滚动支持大数据量
- 改进无障碍访问支持
